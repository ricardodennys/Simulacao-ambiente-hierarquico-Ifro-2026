# Simulacao-ambiente-hierarquico-Ifro-2026

Prática de simulação de ambiente hierárquico e configurações básicas dos switches no Cisco Packet Tracer.

## 🛠️ Configurações Realizadas
* **Hostname:** Definido em todos os switches das camadas de Núcleo, Distribuição e Acesso (EDGE).
* **Autenticação:** Palavra-passe de acesso ao modo privilegiado.
* **Acesso Console:** Proteção da porta de consola.
* **Encriptação:** Criptografia de senhas ativada.
* **Banner:** Mensagem de aviso personalizada na abertura do terminal.
