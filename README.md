# Simulacao-ambiente-hierarquico-Ifro-2026

Prática de simulação de ambiente hierárquico e configurações básicas dos switches no Cisco Packet Tracer.

## 🛠️ Configurações Realizadas
* **Hostname:** Definido em todos os switches das camadas de Núcleo, Distribuição e Acesso (EDGE).
* **Autenticação:** Palavra-passe de acesso ao modo privilegiado (`enable secret`).
* **Acesso Console:** Proteção da porta de consola (`line console 0`).
* **Encriptação:** Criptografia de senhas ativada (`service password-encryption`).
* **Banner:** Mensagem de aviso personalizada na abertura do terminal (`banner motd`).
